Anime Recommender System

Anime_data.csv from: 
https://www.kaggle.com/datasets/marlesson/myanimelist-dataset-animes-profiles-reviews/data?select=reviews.csv

Google Forms:
https://forms.gle/1qjpDi8wpUKcedQ79

This repository contains an Anime Recommender System implemented primarily in Jupyter Notebook and Python. The project was developed as part of an AI assignment, focusing on building a recommendation engine for anime, suitable for educational or game-related applications.

## Features

- Collaborative filtering and/or content-based recommendations for anime.
- Clean data and modular code structure (see the `function/` and `data/` folders).
- Interactive experiments and visualizations via Jupyter Notebook.
